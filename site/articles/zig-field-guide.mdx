## Getting Started

Simply create a Zig file and you're all set.

Zig doesn't require a dedicated project initializiation command.

```zig title="hello.zig" showLineNumbers
const std = @import("std");

pub fn main() void {
    std.debug.print("Hello, {s}!\n", .{"World"});
}
```

```bash
zig build-exe hello.zig
```
